# 🃏 MEME DUEL: สงครามการ์ดเพื่อนแท้ (Friendship Ruiner Card Game)

เกมการ์ดสุดปั่นที่สร้างขึ้นจากภาพมีมเพื่อนทั้งหมด 21 ใบในโฟลเดอร์ กติกาง่าย เข้าใจได้ใน 1 นาที สามารถเปิดเล่นได้ทันทีผ่านเว็บเบราว์เซอร์ หรือจะพิมพ์ลงกระดาษ A4 เพื่อตัดเป็นการ์ดจริงเล่นล้อมวงกับเพื่อนก็ได้!

---

## 🚀 วิธีเปิดเล่นเกมทันที

1. **ดวลออนไลน์ 2 เครื่อง (คอม/มือถือ) ซ่อนการ์ดในมือ ไม่ให้เห็นกัน:**
   - เครื่องที่ 1 (โฮสต์): ดับเบิ้ลคลิกไฟล์ `start_multiplayer.bat`
   - หน้าเว็บจะเปิดขึ้นมา ให้กดปุ่ม **"🏰 ห้อง 4 หลัก (Online)"** -> กด **"กดสร้างห้องใหม่"**
   - จะได้รับ **โค้ด 4 หลัก** (เช่น `4829`) และมีลิงก์ IP แสดงให้เห็นชัดเจน
   - เครื่องที่ 2 (เพื่อนบนมือถือ/แท็บเล็ต/คอมอีกเครื่อง): เปิดเบราว์เซอร์ไปที่ลิงก์ IP นั้น แล้วกด **"ห้อง 4 หลัก"** -> กรอกโค้ด 4 หลัก -> กด **"เข้าร่วมห้อง"**
   - **ระบบซ่อนการ์ด 100%:** บนหน้าจอของแต่ละคนจะเห็นเฉพาะการ์ดในมือของตัวเอง (หน้าการ์ดหงายขึ้นด้านล่าง) ส่วนการ์ดของเพื่อนจะแสดงเป็นหลังการ์ดคว่ำอยู่ด้านบน ไม่สามารถแอบมองการ์ดกันได้!

2. **เปิดเล่นคนเดียวซ้อมมือก่อน:**
   - ดับเบิ้ลคลิกเปิดไฟล์ `start_game.bat` หรือเปิด `index.html` ด้วยเบราว์เซอร์
   - เลือกโหมด **"ดวลกับบ็อต AI"** หรือ **"ดวลกับเพื่อน (สลับกันเล่น 2 คน)"**

3. **โหมดการเล่นที่รองรับ:**
   - 🌐 **โหมดออนไลน์ 2 เครื่อง (ห้องโค้ด 4 หลัก)**: เล่นแยกจอ ไม่เห็นการ์ดกัน
   - 🤖 **โหมดดวลกับบ็อต AI (Vs Bot)**: ซ้อมมือกับบ็อตสุดกวนที่คิดและลงการ์ดโต้ตอบอัตโนมัติ
   - 👥 **โหมดดวลกับเพื่อน 2 คน (Pass & Play)**: สลับกันกดบนเครื่องเดียวกัน
   - 🖨️ **โหมด Print & Play**: แผ่นพิมพ์ A4 ที่จัดวางการ์ดขนาดมาตรฐาน 9 ใบต่อหน้า พร้อมเส้นประสำหรับตัด และลายหลังการ์ด (Card Back) ให้พิมพ์หรือพับประกบ

## 🌐 วิธีนำขึ้นโฮสต์บน Render (Deploy to Render.com)

โปรเจกต์นี้ได้รับการปรับแต่งให้พร้อมดีพลอยบน **Render (Web Service ฟรี)** เรียบร้อยแล้ว รองรับทั้งการเล่นข้ามเครือข่าย/เน็ตมือถือ 4G/5G จากทุกที่ทั่วโลก:

### ขั้นตอนง่ายๆ:
1. **อัปโหลดโปรเจกต์ขึ้น GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Meme Duel Card Game with Render Support"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USER>/<YOUR_REPO>.git
   git push -u origin main
   ```
2. **เปิดเว็บ [render.com](https://render.com) แล้วล็อกอิน:**
   - กดปุ่ม **"New +"** ด้านบนขวา -> เลือก **"Web Service"**
   - เลือกเชื่อมต่อกับ Repository GitHub ของคุณ
3. **ตั้งค่าคอนฟิกบน Render:**
   - **Name:** `meme-duel` (หรือชื่อตามใจชอบ)
   - **Language:** `Node`
   - **Region:** `Singapore` (ใกล้ประเทศไทยที่สุด ปิงน้อย เล่นลื่น)
   - **Branch:** `main`
   - **Build Command:** ปล่อยว่างไว้ หรือใส่ `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** `Free`
   - *(หรือ Render จะอ่านไฟล์ `render.yaml` ที่เตรียมไว้ให้อัตโนมัติ)*
4. **กด "Deploy Web Service":**
   - รอ Render บิลด์ประมาณ 1-2 นาที คุณจะได้ URL HTTPS เช่น `https://meme-duel.onrender.com`
   - เพื่อนเปิดลิงก์นี้จากมือถือหรือคอมที่ไหนก็ได้ในโลก ใส่โค้ด 4 หลัก แล้วดวลกันได้ทันที!

## 📜 ระบบต่อสู้แบบมินเนียน (Hearthstone-style)

- **เป้าหมาย:** ผู้เล่นแต่ละคนมี **HP 30 หน่วย** ใครลด HP ของคู่ต่อสู้เหลือ 0 ก่อน เป็นผู้ชนะ!
- **มานา:** เริ่มต้นที่ **2** เพิ่มสูงสุด **6** แต้ม และรีเฟรชเมื่อเริ่มเทิร์น
- **การจั่วการ์ด:**
  - เริ่มเทิร์นจั่วการ์ดอัตโนมัติ 1 ใบ (มือถือได้สูงสุด 7 ใบ)
- **อัญเชิญ:** ลากการ์ดจากมือมาวางบนสนาม หรือแตะการ์ดเพื่อดูรายละเอียดแล้วกดอัญเชิญ จ่ายมานาตามค่าใช้จ่าย และเรียกได้สูงสุด 7 ตัว
- **ต่อสู้:** มินเนียนที่เพิ่งลงสนามต้องรอหนึ่งเทิร์นก่อนโจมตี แตะมินเนียนพร้อมโจมตีแล้วเลือกมินเนียนศัตรูหรือฮีโร่ มินเนียนที่สู้กันจะแลกดาเมจตาม ATK พร้อมกัน
- **Taunt:** มินเนียนสายแทงค์ปกป้องฮีโร่ คู่ต่อสู้ต้องกำจัดมินเนียนยั่วยุก่อนจึงโจมตีเป้าหมายอื่นได้
- **เอฟเฟกต์อัญเชิญ:** การ์ดแต่ละใบยังคงมีสกิลเฉพาะตัว ซึ่งทำงานเมื่ออัญเชิญลงสนาม
- **ระบบเสียงเอฟเฟกต์:**
  - ใช้ Web Audio API สร้างเสียงหมัด, โล่, การร่ายสกิล, ฮีล, และเสียงฉลองชัยชนะโดยไม่ต้องต่อเน็ต
